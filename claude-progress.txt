## Quick Reference

**Key Commands:**
```bash
# Build and deploy
ssh root@SERVER "cd /path/to/parking-reminder && git pull && docker build -t parking-reminder:2.3.0 . && docker stop parking-reminder && docker rm parking-reminder && source .env && docker run -d ..."

# Test notification
docker exec parking-reminder /usr/local/bin/reminder.sh

# View logs
docker logs -f parking-reminder

# Check state
docker exec parking-reminder ls -la /var/lib/parking-reminder/
```

**Important Decisions:**
- v2.2.0: Replaced Twilio SMS/phone with ntfy priority escalation (simpler, no external API)
- v2.1.0: Extracted shared functions to parking-lib.sh (DRY principle)
- Hybrid bash/Python architecture is committed long-term (no rewrite planned)

**Known Issues:**
- Failsafe notification uses `|| true` (failures silently ignored) - Low priority
